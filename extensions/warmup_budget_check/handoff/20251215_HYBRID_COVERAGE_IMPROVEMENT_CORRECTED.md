## 🔬 技术要点

### 为什么能达到100%？

**算法优势**：
```python
# 贪心算法的综合评分
score = 0.3 * 单因子覆盖度 + 0.7 * 因子对覆盖度

# 每次选择能最大化综合评分的配置
# → 确保因子对的多样性优先被满足
# → 17个配置足够覆盖13个交互对的所有主要值组合
```

**数学原因**：
- 真实因子只有6个（水平数：2-3）
- 交互对的值组合空间不大（如 3×3=9, 2×3=6）
- 17个精心选择的配置 > 覆盖13个交互对所需的最小数量

**对比随机采样**：
- 随机采样可能重复选择相似的配置
- 导致某些值组合被遗漏（93%覆盖）
- 优化采样确保每个值组合都被包含（100%覆盖）
