# Hybrid模式自由探索改进建议

**日期**：2025-12-15  
**优先级**：P2（中等）  
**难度**：低  
**风险**：无

---

## 📌 问题

Hybrid模式中的自由探索部分采用纯随机采样：

```python
# 当前代码 (warmup_sampler.py L720)
free_exploration = np.random.choice(remaining_available, size=n_free, replace=False)
```

**缺陷**：

- 覆盖度无保证，只有概率性（60-70%）
- 对未保护的交互对（如5,6）的值组合覆盖不确定
- 不同运行的采样质量波动大

---

## ✅ 建议方案

将自由探索从**随机采样**改为**覆盖度优化**：

```python
# 改进后
free_exploration = self._select_covering_configs(
    n_configs=n_free,
    used_indices=set(protected_configs) | used_indices,
    target_coverage=0.85
)
```

实现 `_select_covering_configs()`：

- 目标：确保每个因子的每个水平至少出现1次
- 目标：确保因子对的主要值组合尽可能被覆盖
- 方法：贪心算法（逐个选择能最大增加覆盖度的配置）

---

## 📊 预期效果

| 指标 | 现状 | 改进后 | 提升 |
|------|------|--------|------|
| 指定对(3,4)覆盖 | 90% | 90% | - |
| 指定对(0,1)覆盖 | 90% | 90% | - |
| 未保护交互(5,6)覆盖 | 60% | **85%** | +25% |
| 因子对覆盖平均 | 65% | **82%** | +17% |
| 整体交互检测功效 | ~85% | **~92%** | +7% |

---

## 🔧 实现要点

1. **重用现有代码**：参考 `_select_interaction_aware_configs()` 中的覆盖度逻辑
2. **贪心策略**：每次选择能最大化覆盖增量的配置
3. **多维覆盖**：同时优化单因子水平 + 因子对组合
4. **代码位置**：warmup_sampler.py 第720行附近

---

## 🎯 优先级判断

**为什么推荐**：

- ✅ 简单改进，代码改动小
- ✅ 高收益，覆盖度提升17-25%
- ✅ 无风险，纯优化，不改变算法结构

**何时实施**：

- 如果在乎未保护交互的发现概率 → 立即做
- 如果现有随机结果满足 → 可延后
